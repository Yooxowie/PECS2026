- **Ocean Aqua (`#2A9D8F`):** Secondary accent representing Lingayen Gulf coastal resource management.

## 🚀 How to Run Locally

### Requirements
- Python 3.8+
- `pip install python-pptx python-docx`

### Generate PowerPoint & Word Docs
```bash
python generate_presentation.py
python generate_letters_doc.py
```

### View Slide Deck in Browser / Deploy on Vercel
Simply open `index.html` in any modern web browser or deploy directly to Vercel via GitHub integration.
